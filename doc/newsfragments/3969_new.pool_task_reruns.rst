Pool tasks now support partial or full MultiTest reruns (``rerun_entire_task``) and configurable rerun limits, with an option to use a different runner (``rerun_on_different_runner``). These options can also be set globally through the CLI arguments ``--rerun-entire-task``, ``--rerun-limit`` and ``--rerun-on-different-runner``. Tasks that succeed on a rerun are marked ``UNSTABLE``.
