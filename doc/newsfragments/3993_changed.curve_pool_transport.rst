Pool and resource-monitor TCP channels now require ZeroMQ CURVE authentication and encryption before deserialization. Workers receive temporary credentials over private stdin; remote launchers must provide a trusted SSH channel. Custom ``ZMQClient`` and ``ResourceMonitorClient`` callers must supply ``curve_keys``, and custom child entrypoints must read credentials with ``read_curve_keys`` and pass them to ``child_logic``. A CURVE-enabled libzmq is required; plaintext peers are no longer accepted.
